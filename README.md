# Checkpoint 03 — Vinheria Agnello

## Sobre o projeto
O projeto consiste no desenvolvimento de uma página web para a **Vinheria Agnello**, uma empresa familiar especializada na comercialização de vinhos. A página apresenta a marca, seus diferenciais e alguns tipos de vinho, utilizando recursos visuais para proporcionar uma navegação agradável e intuitiva.

O objetivo deste checkpoint é aplicar os conceitos de **Flexbox, pseudo-classes e transformações CSS** na construção de um layout organizado e interativo.

## Tecnologias utilizadas
- HTML5
- CSS3

## Recursos aplicados

### Flexbox
- `display: flex` — organização dos elementos em layouts flexíveis.
- `flex: 1/2/3` — ocupação do espaço disponível no menu de navegação.
- `flex-wrap: wrap` — quebra de linha dos elementos quando necessário.
- `flex-direction: column` — organização vertical dos itens da lista.
- `justify-content: space-between` — distribuição dos elementos com espaço entre eles.
- `justify-content: center` — centralização dos elementos horizontalmente.
- `align-items: center` — alinhamento dos elementos no centro do eixo transversal.
- `align-items: flex-end` — alinhamento dos elementos na extremidade inferior.
- `gap` — definição de espaçamento entre elementos.
- `flex-shrink: 0` — prevenção da redução de tamanho dos elementos decorativos.

### Pseudo-classes
- `:hover` — aplicação de efeitos visuais ao passar o mouse sobre links, botões e imagens.
- `:checked` — identificação de opções de rádio selecionadas.
- `:has()` — seleção de elementos com base na presença de um elemento interno em determinado estado.
- `:first-child` — seleção do primeiro item entre seus irmãos.
- `:nth-of-type()` — No projeto, é utilizada para definir proporções diferentes para os três containers de imagens.

### Pseudo-elementos
- `::before` — criação de elementos decorativos antes do conteúdo.
- `::after` — criação de elementos decorativos depois do conteúdo.
- `::selection` — personalização das cores do texto selecionado pelo usuário.

### Transformações CSS
- `scale(1.1)` — aumento do botão ao passar o mouse.
- `scale(1.05)` — ampliação das imagens ao passar o mouse.
- `translateY(-50%)` — deslocamento vertical do conteúdo da seção de introdução.
- `translateY(-30px)` — deslocamento vertical inicial do conteúdo durante a animação.
- `translateY(0)` — retorno à posição original ao final da animação.

### Transições e animações
- `transition` — suavização das mudanças visuais.
- `@keyframes` — definição de etapas de uma animação.
- `animation` — aplicação da animação de entrada do conteúdo.
- `opacity` — controle da transparência durante a animação.

### Organização e layout
- `box-sizing: border-box` — inclusão de padding e bordas no cálculo das dimensões.
- `margin` e `padding` — controle dos espaçamentos externos e internos.
- `position: relative` e `position: absolute` — posicionamento do conteúdo sobre a imagem de destaque.
- `width` e `height` — definição das dimensões dos elementos.
- `object-fit: cover` — preenchimento da área da imagem sem distorcer suas proporções.
- `border-radius` — arredondamento dos cantos.
- `linear-gradient()` — criação de degradês para detalhes decorativos.
- `cursor: pointer` — indicação de elementos interativos.
- `text-transform: uppercase` — transformação do texto em letras maiúsculas.
- `flex-wrap`, `max-width` e unidades relativas — apoio à adaptação do layout a diferentes espaços.

### Estilização visual
- `background` e `background-color` — definição das cores de fundo.
- `color` — definição da cor do texto.
- `font-family`, `font-size` e `font-weight` — personalização da tipografia.
- `line-height` — controle do espaçamento vertical entre linhas.
- `text-align` — alinhamento do texto.
- `text-decoration: none` — remoção da decoração padrão dos links.
- `list-style: none` — remoção dos marcadores padrão das listas.
- `display: block` e `display: none` — controle da exibição dos elementos.
- `content` — criação de conteúdo decorativo por meio de pseudo-elementos.
